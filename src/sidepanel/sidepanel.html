首次使用，需要配置 MiniMax API Key
1. 点击“申请 API Key”并登录 MiniMax；2. 创建并复制 Key；3. 回到设置页粘贴保存。
试用服务暂未接入，当前使用你自己的 MiniMax API 额度。
🧭 英文网页操作教程
输入“如何操作这个页面”，AI 会逐步高亮按钮。每一步由你确认。
选中段落
还没抓到选中的段落。
  1. 打开一个 PDF（浏览器原生预览或 PDF.js 嵌入网页都可以）
  2. 用鼠标框选一行/一段
  3. 右键 → AI 解释整篇 → 选 AI 智能体
  4. 侧边栏打开后，点下方 📁 选择 PDF 文件 让 AI 拿到整篇内容
等待 PDF 全文加载…

隐私提示：发送问题时，选中段落和你手动选择的 PDF 全文会发送到当前选定的 AI 服务商（MiniMax 或 DeepSeek）处理；插件不提供第三方服务器，也不收集遥测数据。
