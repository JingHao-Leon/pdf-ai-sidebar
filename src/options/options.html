⚙️ PDF AI 设置

配置你要在右键菜单里看到的 AI 智能体。所有 key 仅保存在本地（chrome.storage.sync）。

AI 智能体

支持 MiniMax / DeepSeek

MiniMax 配置教程

  1. 点击“申请 MiniMax API Key”，进入 MiniMax 官方控制台。
  2. 登录后进入“接口密钥”，创建并复制 API Key。
  3. 展开 MiniMax 配置项，把 Key 粘贴到 API Key 输入框，离开输入框后自动保存。
  4. 回到 PDF 页面框选文字，即可使用 MiniMax-M3 解释。

默认智能体

右键菜单默认选中的 agent。快捷键 Ctrl/Cmd+Shift+J 也会用它。

系统 Prompt 模板

用 {context} 表示引用段落，{question} 表示你的问题。

使用说明

  1. 填好上面至少一个 agent 的 API Key。
  2. 打开任意 PDF（浏览器原生预览、PDF.js 嵌入网页都行）。
  3. 用鼠标框选一段文字 → 右键 → PDF AI 提问 → 选 AI 智能体。
  4. 侧边栏自动打开，显示引用段落 + 输入框，输入问题回车即可。
  5. 或按 Ctrl/Cmd+Shift+Y 直接打开侧边栏。
